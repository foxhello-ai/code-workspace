# Worktree / Git 工作台验收

审核版 UI 已落地到实际应用，沿用现有 Git API 与深色界面。

- Worktree：远程地址 → 本地仓库 → 工作目录分组，搜索、仓库及文件状态筛选，列表与详情同屏。
- 名称：独立 clone 统一称为“本地仓库”，通过名称和路径区分；各自显示主工作区及关联 Worktree。
- Git：工作区修改与提交历史标签，文件分类与内联 Diff，图/列表、范围筛选、分页及全屏。
- 上下文：切换模块保留文件选择及已加载历史，支持从详情定位提交及返回原 Worktree。
- 操作：刷新本地状态与获取远程分开；保留分支占用、未提交修改保护及工作区外只读边界。清理仅提供条件预览。

验证结果（2026-10-29）：

- `npm run check` 通过：类型检查、9 个测试文件 / 55 项测试、生产构建。
- 使用临时本地 bare remote、独立 clone、关联/工作区外/目录缺失 Worktree 验证真实 API；共 6 个登记项、2 个本地仓库，历史超过 200 条。
- 开发页面与生产页面均通过浏览器验收，覆盖暂存/未暂存差异、模块切换、保留修改的分支切换、只读清理预览、内联提交 Diff、分页与全屏退出。
- Worktree、修改页和历史页在 320–1440px 宽度下无页面横向溢出；浏览器运行错误为 0。
- 当前本地服务 `http://127.0.0.1:43110` 返回的入口与最新生产构建一致，引用的 JS/CSS 均可读取。
