Code Workspace v1.2.0 改善 Git / Worktree 的查看和操作，并减少打开工作区及外网登录时的等待。

## 主要更新

- **Git / Worktree 工作台**：远程地址 → 本地仓库 → 工作目录分组，新增搜索、筛选、同屏详情、内联统一/并排 Diff、历史图/列表、分页与全屏；切换模块保留选择和历史上下文。
- **先进入工作区再加载**：目录验证后立即进入界面，先展示文件树，后台扫描 Git、登记 Worktree 和启动监听。加载期间可以查看、编辑文件，失败可原地重试。
- **减少重复 Git 查询**：并行扫描仓库与目录，合并重复状态读取，文件树只查询相关仓库，并跳过不需要的逐行变更统计。
- **按需加载网页**：登录、工作区和 Monaco 编辑器分阶段下载；HTML 内置加载界面，模块加载失败可重新加载。
- **压缩与缓存**：提供 Brotli/gzip 静态资源，哈希资源缓存一年，HTML 重新验证，API 使用 `no-store`。
- 包含此前 Windows 配置目录权限修复与局域网 HTTP 会话兼容修复。

Worktree 清理仍只提供预览；分支占用、未提交修改和工作区外只读保护继续生效。

## 安装 / 升级

已有用户重复执行安装命令即可升级，保留配置与密码。升级会重启服务，请先保存编辑内容。

2026-10-30 在线安装脚本修复：macOS/Linux 的脚本、发布包和校验文件下载使用 HTTP/1.1，避免部分网络的 HTTP/2 framing 错误；中断连接会有限重试，SHA-256 校验保持启用。直接使用下面的最新安装命令即可生效。

macOS / Linux：

```bash
curl --http1.1 -fsSL https://raw.githubusercontent.com/foxhello-ai/code-workspace/main/scripts/install.sh | bash
```

Windows PowerShell：

```powershell
irm https://raw.githubusercontent.com/foxhello-ai/code-workspace/main/scripts/install.ps1 | iex
```
